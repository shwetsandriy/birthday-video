# Відео-привітання з днем народження

Односторінковий React-сайт, підготовлений для GitHub Pages.

## Додати відео

Помістіть ваш MP4-файл у `public/birthday-greeting.mp4`.

## Локальний запуск

```bash
npm install
npm run dev
```

## Публікація на GitHub Pages

1. Створіть GitHub-репозиторій і надішліть до нього цей проєкт у гілку `main`.
2. У GitHub відкрийте **Settings → Pages** та виберіть **GitHub Actions** як джерело розгортання.
3. Після завершення workflow сайт буде доступний за адресою `https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПОЗИТОРІЮ/`.

Конфігурація Vite сама підставляє назву репозиторію під час GitHub Actions.
